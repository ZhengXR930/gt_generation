## Vulnerability Analysis Summary

**Location**: `aom_dsp/x86/intrapred_avx2.c` in `highbd_dr_prediction_z1_64xN_avx2`

**Root Cause**: The boundary check at line 1427 only handles the exact boundary condition (`mdif == 0`) but fails to handle negative `mdif` values. When `base + j > max_base_x`, `mdif` becomes negative, but the code falls through to the else branch and performs out-of-bounds reads.

**Triggering Condition**: 
- Requires a 64xN block with high bit depth (10 or 12 bit)
- Directional intra prediction in zone 1 (0° < angle < 90°)
- As `x` accumulates (`x += dx` each row), `base = x >> 6` grows
- When `base < max_base_x` (passes check at line 1410) but `base + 48 > max_base_x`, the vulnerability triggers at j=48 in the loop

**Impact**: Out-of-bounds read from the `above` array, causing a heap buffer overflow read.

The analysis.json has been created with the complete trace from input-controlled block width parameter through the missing boundary check to the out-of-bounds memory access.
