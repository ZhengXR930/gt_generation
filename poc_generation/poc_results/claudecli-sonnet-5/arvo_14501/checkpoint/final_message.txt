3. `decode_hex_digit` casts the signed char to `(unsigned int)`, causing sign extension

The vulnerability stems from the missing validation that the character passed to `decode_hex_digit` is actually a valid hexadecimal digit (0-9, a-f, A-F) before using it as an array index.
