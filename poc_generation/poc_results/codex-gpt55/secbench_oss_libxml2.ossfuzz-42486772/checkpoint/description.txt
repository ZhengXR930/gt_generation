Issue description:
A heap-use-after-free in xinclude.c's xmlXIncludeIncludeNode (seen during xmlXIncludeDoProcess / xmlXIncludeProcessNode invoked from xmlTextReaderRead) reads memory from an XInclude node that has already been freed. This can lead to crashes, memory corruption, or potentially exploitable behavior when processing XInclude content.
