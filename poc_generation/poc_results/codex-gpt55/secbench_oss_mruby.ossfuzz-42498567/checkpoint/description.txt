Issue description:
Heap-buffer-overflow in mrbgems/mruby-compiler/core/codegen.c: the dispatch (and dispatch_linked) code performs a 1-byte out-of-bounds read from a heap buffer during bytecode generation/dispatch. A crafted input can trigger this OOB read, leading to crashes, undefined behavior or potential information disclosure.
