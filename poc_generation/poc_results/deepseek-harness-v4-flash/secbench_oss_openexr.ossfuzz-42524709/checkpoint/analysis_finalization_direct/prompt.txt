Now the EXR header details. Let me write the generator script carefully. Attribute encodings:

- channels (chlist): sequence of channel entries: name (NUL-terminated), then 4 int32: pixelType, pLinear, xSampling, ySampling — each int32 LE. Then a final NUL byte.
  For "Z": "Z\0" + int32(1) [HALF] + int32(0) [pLinear] + int32(1) + int32(1) + "\0".
  Size = 1+1 + 4*4 + 1 = 19.
- compression: 1 byte value 8.
- dataWindow box2i: 4 int32 LE: 0,0,0,0 → 16 bytes.
- displayWindow box2i: same → 16 bytes.
- lineOrder: 1 byte 0.
- pixelAspectRatio: float LE 1.0 → 4 bytes.
- screenWindowCenter v2f: 2 floats → 8 bytes.
- screenWindowWidth: float 1.0 → 4 bytes.

Header ends with a single 0x00 byte.

Then chunk offset table: 8 bytes (uint64 LE) = offset of chunk data. We compute the offset: 8 (magic+version) + sum(header attribute bytes) + 1 (end byte) + 8 (offset table) = chunk start.

Chunk: int32 LE y=0, int32 LE size=70, 70 bytes DWA block.

Total file size = chunk_start + 8 + 70.
