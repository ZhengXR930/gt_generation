A use of an uninitialized value occurs while parsing the subjectAltName extension in TLS certificates. When a GeneralName of type ipAddress has a length other than 4 or 16 bytes, the code leaves the local name buffer without a guaranteed initialized string but still uses `strlen()` and later string-processing routines on it, so the parser reads an uninitialized value instead of enforcing that the buffer contains a valid NUL-terminated name.
