A use-after-free occurs when parsing a vvcc box through `gf_odf_vvc_cfg_read_bs()`. The code installs `on_aom_av1_eos()` as an end-of-stream callback on a `GF_BitStream`, but does not ensure that the callback state remains valid for subsequent reads, so `gf_bs_read_u32()`/`BS_ReadByte()` may invoke the callback with a stale `AV1State *` and write to freed memory via `state->bs_overread = GF_TRUE`.
