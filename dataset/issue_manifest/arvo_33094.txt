An out-of-bounds read occurs when compiling constant expressions in `Compile_If`/`CompileElseBlock`. The expression compiler allocates a code page with `AcquireCodePageWithCapacity` but no longer enforces the restricted opcode set for expression evaluation, so control-flow opcodes such as `if`/`else` can compile arbitrary blocks into a page sized for a simple expression and read past the available code page buffer.
