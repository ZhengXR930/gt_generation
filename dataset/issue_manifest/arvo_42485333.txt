An out-of-bounds read occurs when URI-escaping an IPv6 host with a zone identifier. The IP-literal parser can accept a host like `[...%25zone]` and store it as `addr%zone`, but the URI encoder later treats the `%` in that decoded zone identifier as the start of a percent-encoded sequence without checking that two following characters are available within the string, causing it to read past the end of the host buffer.
