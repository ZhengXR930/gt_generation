Issue description:
A stack-buffer-overflow occurs in the OpenThread MLE response builder when handling a challenge. The code uses the incoming TLV length as the copy size for the response, but the source is a fixed 8-byte challenge field, leading to an out-of-bounds read when the length exceeds 8.
