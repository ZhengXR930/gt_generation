A heap-buffer-overflow write occurs in the TrueType variation handling when a font contains both a 'CFF ' table and 'glyf' data. The code incorrectly zeroes the named-instance count based solely on the presence of the 'CFF ' table, leading to an out-of-bounds write when parsing named instances.
