Issue description:
In the DNS label decoding routine, a second pass over a packet can misinterpret bytes as a compressed-label pointer, computing an attacker-controlled offset that points outside the packet. The code then dereferences this wild pointer to compute the next label, leading to a heap-buffer-overflow read.
