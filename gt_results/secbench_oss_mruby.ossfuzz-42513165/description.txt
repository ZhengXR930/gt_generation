Issue description:
Heap-use-after-free in mruby-bigint: mpz_init_set_str (mrbgems/mruby-bigint/core/bigint.c), invoked via mrb_bint_new_str, can read from freed or otherwise invalid heap memory when initializing a BigInt from a string. This results in a crash (SEGV) and potential memory corruption, with possible denial-of-service or further exploitation.
