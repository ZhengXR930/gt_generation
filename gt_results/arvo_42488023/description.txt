Issue description:
In the msgpack-to-GELF conversion, the float formatting routine stores the formatted string in a fixed-size stack buffer but records the full length that snprintf would have written. This length is later used in a memory copy, causing a stack-buffer-overflow read when the formatted string exceeds the buffer size.
