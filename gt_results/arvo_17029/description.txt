Issue description:
A stack buffer overflow write occurs during slice header parsing when processing the reference picture lists. The slice header structure is cleared with `memset()` before parsing, but for dependent slices the code then copies the previous slice header only when the current slice index is greater than 0, leaving the first parsed dependent slice with zeroed reference-list counts; `ihevcd_ref_list()` later uses these unchecked values to write past a fixed-size stack buffer.
