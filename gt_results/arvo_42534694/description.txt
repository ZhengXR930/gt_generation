Issue description:
The GUID section-length validation uses a logical AND instead of OR, so a candidate with only some malformed sections is accepted. This allows a subsequent fixed-size memcpy from the last GUID field to read past the end of the heap-allocated string, causing a heap-buffer-overflow.
