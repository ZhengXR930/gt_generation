Issue description:
An out-of-bounds read occurs in TACACS argument decoding when an argument value for an OCTETS attribute is passed to `fr_pair_value_from_str()` and interpreted as base16. The value buffer is length-delimited by `arg_end - value`, but the base16 validation/decoding path can read past the end of that non-null-terminated buffer because it does not enforce the provided length.
