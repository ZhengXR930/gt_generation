Issue description:
A use of uninitialized value occurs in `UA_base64()` when encoding a `ByteString` to JSON. For some input lengths, the temporary output byte `c` used to form the final Base64 characters is read before all bits have been initialized, so the encoded output can depend on uninitialized memory.
