Issue description:
An out-of-bounds read occurs in TopicTree when unlinking a drainable subscriber from the internal linked list. If the removed subscriber is the head of `drainableSubscribers`, the code clears the head pointer without preserving the next element, leaving the list in an invalid state so later traversal can read through stale subscriber links.
