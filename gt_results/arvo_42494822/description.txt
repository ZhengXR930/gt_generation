Issue description:
A malformed child box larger than the remaining container payload is not properly rejected; the code only logs a warning and zeroes the container size, leaving the oversized child in the parent's ownership lists. Later, during generic box destruction, the child_boxes list is traversed, and a freed GF_ESDBox pointer is dereferenced, leading to a heap-use-after-free read.
