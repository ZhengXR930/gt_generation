Issue description:
A heap buffer overflow occurs in DIMS scene configuration box parsing when reading the null-terminated textEncoding and contentEncoding strings. The code reads bytes into a temporary buffer up to the remaining box size and then passes it to `gf_strdup()` without ensuring that a terminating NUL was present, so `strdup` can read past the end of the allocated buffer.
