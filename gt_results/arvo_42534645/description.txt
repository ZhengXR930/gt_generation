Issue description:
An out-of-bounds read occurs in `streamProperties()` when it reads the stream type GUID and passes the buffer to `GUIDTag`. The code does not enforce that the I/O layer returned all `GUID` bytes, so `GUIDTag` can consume a partially filled buffer and `memmove` may read past the end of the valid data.
