Issue description:
An out-of-bounds read occurs in `abst_box_read()` when parsing string fields from an ABST box. The code copies bytes into a temporary buffer and then passes it to `gf_strdup()` even if no NUL terminator was found before the box data ended, so `gf_strdup()` may read past the end of the buffer while looking for the end of the string.
