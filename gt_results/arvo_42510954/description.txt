Issue description:
An uninitialized value is read when parsing a signed `inf` float constant in `Parser::Next()`. The code checks the character after `inf` using `cursor_[4]` instead of the actual next character, so it examines the wrong byte and does not correctly enforce that the token is not followed by an identifier or digit.
