Issue description:
Heap-use-after-free in libxml2: xmlValidateRef (src/valid.c) can dereference an xmlAttr/xmlRef pointer that has already been freed when using the validating XML reader. The validator walks the document's reference table and may read stale pointers to attributes removed by the reader, leading to a heap-use-after-free that can cause crashes or other memory-corruption impacts.
