Issue description:
A stack buffer overflow read occurs during Parent Response processing when the Response TLV is compared with the saved parent request challenge using `memcmp()` and the length taken from the received response. The code does not enforce that the attacker-controlled response length is bounded by the size of `mParentRequest.mChallenge`, so the comparison can read past the end of that stack buffer.
