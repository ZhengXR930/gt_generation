Issue description:
A heap use-after-free occurs while nested paths from malformed archive entries are materialized. During replacement of a file entry with a directory, KArchive path creation can retain a stale entry and return a directory pointer that duplicate-name handling has already deleted; recursive path processing later uses that pointer.
