Issue description:
An out-of-bounds read occurs in `stsz_box_read()` when parsing compact sample size tables. For `sampleSize == 4`, the code reads one or two 4-bit sample sizes per loop iteration but then updates `max_size` and the size counters using `ptr->sizes[i]` after `i` has already been advanced, so it accesses `sizes` past the end of the allocated sample-size array when the last entry or pair is processed.
