Issue description:
An out-of-bounds read occurs in `SSLClientHelloMessage::getCipherSuiteID()` when accessing a cipher suite by index. The code computes the start of the cipher suite list from the parsed ClientHello fields but only checks that one `uint16_t` is present at the beginning of the list, and does not enforce that `cipherSuiteStartOffset + sizeof(uint16_t) * (index + 1)` remains within `m_DataLen` before reading the requested entry.
