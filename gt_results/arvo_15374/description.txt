Issue description:
A stack out-of-bounds read occurs when processing a Mesh Local Prefix TLV in a dataset set request. The code compares `meshLocalPrefix.GetMeshLocalPrefix()` with the local mesh-local prefix using `memcmp()` and `meshLocalPrefix.GetLength()` bytes, but it only checks that the TLV length is at least the size of the prefix field, not that it is exactly that size, so an oversized length causes `memcmp()` to read past the end of the stack-allocated `MeshLocalPrefixTlv` object.
