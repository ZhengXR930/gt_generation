Issue description:
An out of bounds read occurs in LoadVoiceVariant() via LoadVoice() when an invalid long option reaches the getopt compatibility code. Error reporting passes `current_argv` to `fprintf` with a `%s`-style format, but the option text is only tracked with `current_argv_len` and is not guaranteed to be NUL-terminated, so `fprintf` may read past the end of the argument buffer.
