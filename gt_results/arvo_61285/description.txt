Issue description:
A heap buffer overflow read occurs in `parse_complex_format()` when it calls `read_key_figures()` with the full string length as the `half_length` argument. This does not enforce that the number of bytes read from `input` fits within the allocated buffer, so `read_key_figures()` can read past the end of the heap buffer.
