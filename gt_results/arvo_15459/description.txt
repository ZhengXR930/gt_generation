Issue description:
In c-ares's ares_parse_aaaa_reply, the loop that fills the addrttls array checks only that the pointer is non-NULL, not that the index is within the caller-provided capacity. This allows writing past the end of a 5-element stack array when the response contains more than 5 addresses.
