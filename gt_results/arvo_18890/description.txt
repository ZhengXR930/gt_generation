Issue description:
A heap double free occurs in public key object decoding when ASN.1 parsing fails after allocating the direct-value buffer in `obj->content.value`. The decode path frees `der->value` locally on error without clearing the object content, so later object cleanup frees the same heap buffer again in `sc_pkcs15_free_object_content()` via `sc_pkcs15_free_object()`.
