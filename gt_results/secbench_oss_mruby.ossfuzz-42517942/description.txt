Issue description:
An index-out-of-bounds write in mruby's pack/unpack handling: malformed pack templates can cause unpack_hex / pack_unpack (mrbgems/mruby-pack/src/pack.c) to drive string creation with an incorrect size, leading to an out-of-bounds write in str_new -> str_init_embed (src/mruby/src/string.c). This can crash the process (SIGSEGV) and cause memory corruption, potentially enabling further exploitation.
