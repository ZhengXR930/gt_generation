Issue description:
A negative-size memory copy can occur in `php_fgetcsv()` while parsing a CSV field with an unterminated enclosure and a NUL escape character. Cleanup can move the current pointer behind the saved field start without adjusting both pointers, so the final field copy computes a negative length.
