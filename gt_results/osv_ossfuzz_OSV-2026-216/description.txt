Issue description:
A heap buffer over-read occurs when Mongoose parses an MQTT 5 binary-data property whose declared length exceeds the remaining packet. `mg_mqtt_next_prop()` validates the two-byte length field but not the referenced payload extent, so later processing consumes bytes beyond the input buffer.
