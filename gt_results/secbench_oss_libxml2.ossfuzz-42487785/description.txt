Issue description:
Heap-use-after-free in XInclude processing: xmlXIncludeLoadTxt (xinclude.c) can end up calling xmlStaticCopyNode (tree.c) on a node that has already been freed (by the XML reader code), resulting in a read of freed heap memory. An attacker-controlled XML with XInclude can trigger this, causing crashes, memory corruption, or potentially enabling information disclosure or further exploitation.
