Issue description:
A global buffer over-read occurs during shorthand section parsing when parse_section() appends a section name from a lexeme whose length is zero. The code passes lexeme->value.value to lwan_strbuf_append_str() without enforcing that an empty lexeme has a valid readable buffer, so it can read from an invalid global buffer location.
