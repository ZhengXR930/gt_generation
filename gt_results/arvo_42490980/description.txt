Issue description:
An out-of-bounds write occurs in CFF2 blend handling when the `blend` operator is executed with a number of operands that is not validated against the current charstring stack depth. In `cff_parser_run`, `cf2_doBlend()` computes indices from the untrusted `numBlends` value and writes blended results back into the operand stack without ensuring that `numBlends * lenBV` operands are actually present, allowing writes outside the stack buffer.
