Issue description:
During JSON encoding of a message pack, the UTF-8 escape sequence for a high-byte character is written without ensuring sufficient space in the output buffer. The check only verifies 6 bytes are available, but the formatted escape can be 8 bytes long, causing a heap-buffer-overflow when the terminator is written.
