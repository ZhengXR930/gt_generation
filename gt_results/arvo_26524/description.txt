Issue description:
A heap buffer overflow read occurs during EXIF parsing when `vips__exif_parse()` passes image metadata to `exif_data_load_data()` via `vips_exif_load_data_without_fix()`. The EXIF loader reads fields from the supplied `data` buffer without enforcing that offsets and component sizes remain within the provided `length`, allowing reads past the end of the heap buffer on malformed EXIF data.
