Issue description:
A heap buffer overflow write occurs in entity parsing for JSX child tokens when `fxGetNextEntity()` writes the initial `&` byte to the entity buffer without first checking that space remains. If the buffer pointer is already at the end of the allocated range, this store writes past the heap buffer because the bound is not enforced for that first character.
