Issue description:
In the negative-cbytes decoding path of the chunk decompressor, when the token's low bit is clear, the code fails to initialize the output length and normalize the remaining byte count. The subsequent loop epilogue then reads the uninitialized length and rewinds the source pointer by the stale negative value, leading to a use-of-uninitialized-value defect.
