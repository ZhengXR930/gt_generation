Issue description:
An out-of-bounds read occurs when decoding percent-encoded URI components. If the input buffer is not NUL-terminated and its final or penultimate byte is `%`, the decoder may read 1 or 2 bytes past the end of the buffer because it does not verify that the bytes following `%` are present before checking them.
