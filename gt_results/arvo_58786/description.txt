Issue description:
An integer overflow can occur during arithmetic used to compute `desc_start` and `size` while processing note header fields such as `nhdr->n_namesz`, `nhdr->n_descsz`, and alignment values. The code does not ensure these derived additions and size calculations stay within range before using `size`, which can result in an invalid oversized value being accepted.
