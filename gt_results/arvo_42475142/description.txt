Issue description:
An uninitialized value is used when printing the PowerPC `TBEGIN` instruction. The instruction descriptor and asm-writer tables disagree about `TBEGIN`'s operand layout, so `printU1ImmOperand()` reads operand 0 as a 1-bit immediate even though that operand is not enforced to be an initialized immediate value for this instruction.
