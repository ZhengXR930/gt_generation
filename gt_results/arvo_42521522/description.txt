An out-of-bounds read occurs while decoding the superblock or driver info prefix during metadata checksum verification. The code reads fields such as the signature, version, address/size bytes, reserved bytes, length, and driver name from the on-disk image buffer without enforcing that the supplied buffer is large enough for those accesses.
