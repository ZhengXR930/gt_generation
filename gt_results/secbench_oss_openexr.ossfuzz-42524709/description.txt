Issue description:
A heap-buffer-overflow (out-of-bounds read) occurs during DWA decompression: while parsing compressed DWA blocks in DwaCompressor_uncompress (internal_dwa_compressor.h) via exr_uncompress_buffer and libdeflate_zlib_decompress_ex, a 16-bit unaligned read (get_unaligned_be16/load_u16_unaligned) can read two bytes past the end of the input buffer for malformed compressed data. This can crash the process (DoS) and may lead to information disclosure or further memory corruption when processing crafted EXR files.
