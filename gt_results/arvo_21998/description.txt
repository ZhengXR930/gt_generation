Issue description:
A heap use-after-free read occurs during regexp compilation when look-behind analysis fails to mark a referenced capture group as used. In `tune_tree`, the code can continue to compute byte lengths for a node through `tune_quant` and `node_min_byte_len` after the referenced group has been freed, because the check for BAG_MEMORY nodes does not enforce that `NODE_IS_REFERENCED(node)` is treated as a use.
