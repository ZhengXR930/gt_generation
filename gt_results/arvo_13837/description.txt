Issue description:
A heap buffer over-read occurs during ASN.1 private key parsing when validating the algorithm parameters element. The code can call `ptls_asn1_validation_recursive(bytes + byte_index, last_byte1 - byte_index, ...)` even after an earlier decode error has left `byte_index` past `last_byte1`, so the remaining length underflows and a bounds check on the nested ASN.1 buffer is not enforced.
