Issue description:
A heap buffer over-read occurs while libcoap parses an extended token length from a header-only PDU. A zero-payload PDU places its token pointer at the end of the allocation, but `coap_pdu_parse_header()` reads the first token byte without ensuring that any token data was allocated.
