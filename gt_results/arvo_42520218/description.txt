Issue description:
An out-of-bounds read occurs when decoding the superblock prefix in `H5F__cache_superblock_get_final_load_size()`. The code in `H5F__superblock_prefix_decode()` reads fields from the on-disk image buffer, including the signature and address/size bytes, without enforcing that the supplied `image_len` is large enough for those accesses, which can cause `memcmp` and subsequent parsing to read past the end of the buffer.
