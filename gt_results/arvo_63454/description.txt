Issue description:
In the STUN message integrity check, the return value of strncpy is incorrectly assigned to a size_t variable, overwriting the buffer length with a stack address. This corrupted length is then used in a memcmp that reads beyond the actual buffer into uninitialized memory, leading to a use-of-uninitialized-value defect.
