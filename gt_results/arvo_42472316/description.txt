Issue description:
A heap-buffer-overflow occurs in h2o's HTTP/2 scheduler when a stream is closed. The code moves a live scheduler reference into a truncated closed-stream stub without deactivating it, leaving a dangling reference. This leads to an out-of-bounds read of 8 bytes when the callback treats the stub as a full stream and accesses `_data.size`.
