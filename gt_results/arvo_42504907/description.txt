Issue description:
An out-of-bounds write occurs during number translation in `TranslateNumber_1()`. The function reads digits and related suffix text from `word` and builds fixed-size local character buffers such as `suffix[30]`, but it does not enforce that the copied suffix content fits within that buffer, allowing data derived from the input word to be written past the end of the stack buffer.
