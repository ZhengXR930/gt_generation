Issue description:
An out-of-bounds write occurs in rule translation when copying the input word into the fixed-size stack buffer `word_copy`. The loop copies bytes from `p_start` until a NUL byte is seen, but if the input is not NUL-terminated within `N_WORD_BYTES - 1` bytes the subsequent `word_copy[ix] = 0` writes past the end of the buffer because termination within the destination size is not enforced.
