Issue description:
An out-of-bounds read occurs in ReadClause when processing a character sequence and unconditionally fetching a second character with GetC(). If the input ends after the first character, no end-of-input check is enforced before reading the next UTF-8 code unit, causing the decoder to read past the end of the buffer.
