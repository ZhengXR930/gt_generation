Issue description:
A heap-buffer-overflow occurs in HarfBuzz's subsetting code when handling a malformed dfont. The `resourcesZ` field is treated as a nullable offset, allowing an impossible `ResourceRecord` array to be rewritten to 0 instead of causing sanitization to fail. This leads to an out-of-bounds read of 4 bytes when comparing tags in a fake `OpenTypeFontFace`.
