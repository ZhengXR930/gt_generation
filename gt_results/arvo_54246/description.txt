Issue description:
A heap use-after-free read occurs in HEIF decoding error handling in ensureDecoder(). When heif_decode_image() fails, the code frees the libheif context and then logs err.message, even though the error message buffer may be owned by the freed context, so the read of the message is not guarded by object lifetime.
