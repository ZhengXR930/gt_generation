Issue description:
A stack-based buffer overflow exists in ZipArchiveIOSystem::MapArchive when copying a filename extracted from a zip file into a 256-byte filename buffer. The function does not enforce that the filename length fits within the fixed-size buffer, so filenames longer than 256 characters can write out of bounds.
