Issue description:
An uninitialized value is used when Arabic mark reordering moves combining marks and updates cluster boundaries. In this path, `merge_out_clusters()` can pass an uninitialized cluster value to `set_cluster()` for the range being reordered because the code does not ensure that the cluster value used for the merge has been initialized before merging the marks.
