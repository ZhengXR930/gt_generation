Issue description:
In FreeRADIUS DNS label decoding, the length passed to the uncompressed length function is incorrectly calculated as a packet-relative offset rather than the actual remaining length. This causes the function to read beyond the buffer when parsing a truncated compressed pointer, leading to a heap-buffer-overflow.
