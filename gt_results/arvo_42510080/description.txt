Issue description:
An uninitialized memory read occurs in the generated xlate functions used by ELF data conversion. When the input length is not an exact multiple of the destination structure size, the trailing partial structure bytes are left undefined instead of being copied, and later operations such as compression may compare those undefined bytes with `memcmp`.
