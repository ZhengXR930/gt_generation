Issue description:
A heap use-after-free read occurs when parsing ancillary chunks before the first IDAT chunk. The code keeps a pointer to `ctx->data` across chunk reads, but reading the next chunk can reallocate or replace that buffer, and later ancillary-chunk processing accesses the stale `data` pointer without ensuring it still refers to live storage.
