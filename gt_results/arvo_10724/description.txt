Issue description:
A use of an uninitialized value occurs in the fallback kerning logic when checking whether the current glyph has the kern mask. The code tests `buffer->cur().mask` while iterating with `idx`, but the current-buffer cursor is not initialized or synchronized with that index, so the mask check can read an uninitialized `cur()` value instead of `info[idx].mask`.
