Issue description:
An out-of-bounds read occurs in ucl_object_copy_internal when copying object keys that contain embedded null bytes, such as keys decoded from JSON strings with \u0000 in ucl_unescape_json_string. The key copy operation treats the key as a null-terminated string instead of using the full key length, so the complete key data is not copied correctly.
