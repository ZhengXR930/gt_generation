Issue description:
A heap buffer over-read occurs in coap_split_uri_sub() when parsing a URI with a zero-length input buffer. The code dereferences the first byte of the URI string while checking for a leading '/' without first enforcing that the supplied length is nonzero, so coap_get_uri_path() can read past the end of the heap buffer.
