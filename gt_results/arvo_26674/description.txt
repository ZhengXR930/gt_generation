Issue description:
A heap-buffer-overflow occurs in the embedded font decoder when the input size is a multiple of 4. The allocation size calculation subtracts 1 from the unsigned remainder before clamping, causing an under-allocation of one byte. The decode loop then writes one byte past the end of the buffer.
