Issue description:
A global buffer over-read occurs when MD4C parses input that combines table syntax with an admonition inside a quote block. The admonition fast path leaves the previous table-line state active, so the next line reaches `md_start_new_block()` with an unsupported line type and indexes beyond its generated switch table.
