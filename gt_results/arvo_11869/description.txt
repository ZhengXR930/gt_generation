Issue description:
An integer overflow exists in the handling of `ofpact_learn_spec->n_bits`, which stores the size of the immediate data following `ofpact_learn_spec`. In multiple places this field is assigned directly from `mf_subfield->n_bits`, an `unsigned int`, without enforcing that the value fits in the `uint8_t` destination, so sufficiently large input can wrap the size value.
