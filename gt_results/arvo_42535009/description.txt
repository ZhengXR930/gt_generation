Issue description:
The return value of FLAC__stream_decoder_get_decode_position() is ignored, so the caller assumes the output variable was initialized even when the function fails (e.g., for Ogg decoders). This leads to the use of uninitialized values in subsequent frame analysis, causing a use-of-uninitialized-value error.
