Issue description:
The objdump binary reader mishandles the end of an element segment initializer expression. When the init-expression reader reaches the section end without encountering an END opcode, it still reports success, leaving the expression type uninitialized. The subsequent switch on this uninitialized type reads indeterminate data, causing a use-of-uninitialized-value defect.
