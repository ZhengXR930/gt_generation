Issue description:
A use-of-uninitialized-value occurs in HarfBuzz's sanitizer when processing a malformed dfont. The `resourcesZ` field uses a null-safe `OffsetTo`, so sanitizer failure on the resource-record list is repaired by zeroing the offset instead of rejecting the malformed input. This leads to an uninitialized read during a binary search on the table directory.
