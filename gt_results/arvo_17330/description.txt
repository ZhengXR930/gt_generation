Issue description:
A stack-buffer-overflow occurs in the OpenThread network data handling when processing a Commissioning Get request. The handler copies a length-controlled TLV value into a fixed 254-byte stack buffer without verifying that the TLV is non-extended or that the value fits, leading to a write past the buffer end.
