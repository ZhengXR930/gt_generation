Issue description:
An out-of-bounds read occurs when decoding %-encoded URI components. If the input buffer is not NUL-terminated and its final or penultimate byte is '%', the code reads 1 or 2 bytes past the end of the buffer because it does not verify that the hexadecimal digits after '%' are present within the buffer.
