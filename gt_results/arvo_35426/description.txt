Issue description:
A heap buffer overflow read occurs in the TGA loader when processing TGA image data. The code reads pixel data from a heap buffer without ensuring that the input contains enough bytes for the requested pixel depth or run length, so crafted TGA data can cause reads past the end of the allocated buffer.
