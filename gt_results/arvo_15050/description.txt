Issue description:
In readstat's SPSS command parser, the quoted-string copy helper truncates the input length to the full destination size without reserving a byte for the terminating NUL. When the source is exactly the buffer length, the subsequent write of the terminator overflows the 1024-byte stack buffer by one byte.
