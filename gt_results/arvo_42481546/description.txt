Issue description:
An out-of-bounds read occurs during PKCS#8 private key import when a GOST key is fixed up using a curve identifier that is accepted but mapped to the wrong or unsupported curve parameters. The code does not enforce that the selected GOST curve matches a valid supported curve before performing scalar multiplication, so the ECC table lookup in `_nettle_sec_tabselect` can read past the end of the precomputed table.
