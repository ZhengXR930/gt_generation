Issue description:
A heap buffer over-read occurs during AMQP message decoding when parsing a list value. In `consume_list()`, the encoded list size field is trusted to initialize the subconsumer and advance the input position without checking that the declared size fits in the remaining input buffer, so a malformed message can cause reads past the end of the heap buffer.
