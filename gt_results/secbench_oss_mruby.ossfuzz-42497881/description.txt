Issue description:
mrb_str_format in mrbgems/mruby-sprintf/src/sprintf.c computes an incorrect (overflowed/negative) length when parsing numeric format specifiers, which can cause memcpy to be called with a negative size (ASAN "negative-size-param"). This leads to crashes and can result in out‑of‑bounds heap memory access or corruption, potentially enabling exploitation.
