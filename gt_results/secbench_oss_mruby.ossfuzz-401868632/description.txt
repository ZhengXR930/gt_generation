Issue description:
Heap-buffer-overflow in src/range.c (range_num_to_a): while converting numeric ranges to an array the function can write an 8-byte value past the end of the allocated array (out-of-bounds write). This corrupts heap memory and can lead to crashes or potential arbitrary code execution when handling certain numeric ranges (e.g., mixes of integers and floats).
