Issue description:
An out-of-bounds read occurs in `g_resolver_records_from_res_query()` when parsing a DNS response shorter than `sizeof (HEADER)`. The code treats `answer` as a `HEADER` and reads fields such as `qdcount` without first enforcing that `len` is large enough for the fixed-size header.
