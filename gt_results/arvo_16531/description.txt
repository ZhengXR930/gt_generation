Issue description:
A vulnerability exists in the original string conversion API when UCS-2 or UCS-4 input is passed with a length of -1, allowing null-terminated wide-character strings to be processed without enforcing the correct character width for termination. In addition, DecodeDirect can over-read by 1 to 3 bytes when reading UCS-2 or UCS-4 strings with a provided size.
