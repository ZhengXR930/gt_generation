Issue description:
An out-of-bounds read occurs in GSUB closure computation because `hb_auto_t` accepts arbitrary constructor arguments and may copy a referenced object instead of preserving the reference or pointer. In the closure path this can leave `_hb_void_t`/`return_t` operating on an unintended copied value, so bounds information is not preserved and lookup substitution closure may read past the valid buffer.
