Issue description:
An uninitialized value is used when recording instruction groups for MOS65XX instructions. In `fillDetails()`, the code increments `detail->groups_count` without initializing it first, and later `MOS65XX_group_name()` may use this uninitialized count to access entries in the groups array without enforcing that the index refers to a valid initialized element.
