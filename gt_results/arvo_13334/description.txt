Issue description:
In OpenThread's Network Data, the Prefix TLV validation allows prefix lengths that exceed the size of an IPv6 address. When `GetNextOnMeshPrefix()` copies the prefix into a stack-local buffer, it writes more bytes than the 16-byte destination can hold, resulting in a stack-buffer-overflow.
