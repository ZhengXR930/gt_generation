Issue description:
A use of uninitialized value occurs in `wolfSSL_HmacCopy()` when `src->macType` selects a hash algorithm whose copy routine leaves `ret` uninitialized before it is tested with `if (ret != 0)`. The function does not enforce that `ret` is initialized on all paths for the selected `macType`, and `wolfSSL_HMAC_CTX_copy()` can therefore propagate an HMAC context copy through an uninitialized status value.
