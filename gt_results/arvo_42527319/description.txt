Issue description:
An out-of-bounds write can occur in CRC24Q packet handling when packet_parse() derives a payload length from the bytes following the 0xd3 marker without enforcing that the marker offset and decoded length are within the received input buffer. A malformed packet can cause crc24q_check()/crc24q_hash() to operate past the end of the packet data because the parser trusts the extracted length field.
