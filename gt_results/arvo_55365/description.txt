Issue description:
A heap use-after-free read occurs in torrentzip checking when a layered source created with `zip_source_crc_create()` is opened after its underlying window source has been freed. The code does not keep the wrapped `src_window` alive for the lifetime of `src_crc`, so opening and reading the CRC source can access freed heap memory.
