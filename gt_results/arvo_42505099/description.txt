Issue description:
A heap buffer over-read occurs in `setcharset` during wildcard pattern matching when the pattern string ends with an open bracket (`[`). In the default pattern matching function, the code does not ensure that the pattern is complete before processing the character set, which can cause it to read past the end of the pattern buffer.
