Issue description:
A use of uninitialized memory occurs in the Karatsuba multiplication code when splitting the operands into high and low halves. The temporary big number `b0` is allocated with a size derived from `a->used - h` instead of its actual `used` value `h`, so later operations such as `bn_add()` may read uninitialized digits from `b0` through `bn_add_imp()` and `bn_trim()` because the buffer size does not match the number of initialized limbs.
