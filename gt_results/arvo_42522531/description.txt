Issue description:
An out-of-bounds read occurs during group object lookup when a symbol table node entry name is compared with `strcmp()` without ensuring that the on-disk name buffer is NUL-terminated within its allocated length. A malformed file can provide a group entry name that lacks a terminator, causing the comparison to read past the end of the name buffer while searching the symbol table.
