Issue description:
A use of uninitialized value occurs when reordering Arabic combining marks. The code moves glyphs within `buffer->info` and then merges clusters over the affected range using an operation that can examine cluster data for glyph entries whose cluster values have not been initialized, because the cluster-merge operation is not restricted to initialized cluster information during this reordering.
