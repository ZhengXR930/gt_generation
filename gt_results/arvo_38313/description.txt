Issue description:
A heap buffer overflow write occurs in `blosclz_compress()` when calculating the output limit from `output + maxout` before validating that `maxout` is large enough. If `maxout` is negative or otherwise invalid, the computed `op_limit` can point outside the allocated output buffer, and subsequent match or literal encoding can write past the end of the heap buffer because the output bound is not properly enforced.
