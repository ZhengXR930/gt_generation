Issue description:
In the AVX2 highbd directional prediction path, the chunk guard for the z1 64xN case only handles the exact-boundary condition and misses negative distances. When the reference index already exceeds the last valid position, a negative `mdif` falls through to an unchecked 16-byte load pair, causing a stack-buffer-overflow read.
