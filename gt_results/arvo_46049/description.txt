Issue description:
A heap buffer overflow read occurs while parsing a regular expression branch into a string node. In `onig_node_str_cat()`, the parser appends bytes from the pattern to the node without ensuring that the source pointer and requested length remain within the allocated pattern buffer, so a malformed expression can cause reads past the end of the heap buffer.
