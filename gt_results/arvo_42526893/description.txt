Issue description:
An out-of-bounds read occurs in `getDstIPv4Address()` when iterating over NFLOG TLV records. The code uses the unaligned `recordLen` field as the TLV size and does not enforce 4-byte alignment/padding, so it can advance into the middle of padded data and read a subsequent TLV header from the wrong offset.
