Issue description:
In OpenThread's MLE network data serialization, the maximum leader network data size is set to 255, but generic TLV parsing treats 255 as an extended-length marker. This causes the append operation to copy more bytes than the stack-allocated TLV object actually holds, leading to a stack-buffer-overflow.
