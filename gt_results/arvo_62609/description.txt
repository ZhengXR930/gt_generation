Issue description:
An out-of-bounds read occurs during HTTP chunked transfer parsing in `getchunk()`, used from `deliver_chunked_chunks` via `http_cb`. The code accepts a chunk length line without enforcing that it contains only hexadecimal digits before converting it with `mg_unhexn()`, which can produce an incorrect chunk size and cause reads past the end of the buffered chunk data.
