Issue description:
In the configuration file parser, when a line exceeds both the maximum number of arguments and the maximum line length, the error handling for too many arguments is performed before the buffer is resized. This causes the code to access an argument pointer that lies beyond the current buffer allocation, leading to a heap-buffer-overflow when formatting the error message.
