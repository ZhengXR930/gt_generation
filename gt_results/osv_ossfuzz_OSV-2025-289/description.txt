Issue description:
A stack buffer over-read occurs while OpenThread prints a DNS record response whose query name fills the entire destination buffer. Query-name extraction can fail without leaving a terminating NUL, but the CLI callback ignores that failure and passes the unterminated name to `OutputLine()` as a string.
