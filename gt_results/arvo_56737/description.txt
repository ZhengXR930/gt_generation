Issue description:
In HashMgr::free_flag, the alias length parameter is narrowed from a 32-bit integer to a signed short. For a length of 32768, this truncation yields a negative value, which is then used as the bound in a binary search. This results in an out-of-bounds read that is detected as a heap-use-after-free.
