Issue description:
An out-of-bounds write can occur in GRE payload parsing when a payload with EtherType `PCPP_ETHERTYPE_PPP` is treated as a `PPP_PPTPLayer` without first verifying that the buffer is at least `sizeof(ppp_pptp_header)` bytes long. This allows `computeCalculateFields()` to operate on an undersized packet buffer as if a full PPP-PPTP header were present, writing past the end of the provided data.
