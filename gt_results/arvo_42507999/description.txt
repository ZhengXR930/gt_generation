Issue description:
A heap-based out-of-bounds write occurs in diST_box_read() when reading the content_script_types string from a diST box. The code copies bytes into a fixed 1024-byte local buffer until a NUL byte is encountered, but it does not enforce that the string length stays within the buffer or within the box size.
