Issue description:
A use after free occurs in BaseProcess::ExecuteOnScene() when an exception is thrown during Execute(). The function deletes `pImp->Pimpl()->mScene` in the catch block, but the `progress` member has already been set from `pImp->GetProgressHandler()` and its lifetime is not enforced, so subsequent use of that handler can access freed memory.
