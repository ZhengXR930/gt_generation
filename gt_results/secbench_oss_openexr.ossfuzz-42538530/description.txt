Issue description:
An invalid memory read (segmentation fault) occurs in internal_exr_validate_shared_attrs (src/lib/OpenEXRCore/validation.c). During header parsing (internal_exr_parse_header) the code invokes memcmp on attribute data that can reference out-of-bounds or uninitialized memory for crafted/malformed files, causing a crash. This can be triggered by attacker-supplied inputs and leads to denial-of-service during OpenEXR header validation.
