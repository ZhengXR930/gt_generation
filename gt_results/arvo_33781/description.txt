Issue description:
An out of bounds read occurs in string escaping when non-ASCII escaping is enabled. `escape_string()` decodes a code point with `unicode_traits::to_codepoint(it, end, cp, ...)` and then unconditionally sets `it = r.ptr - 1`, but it does not enforce that `r.ptr` advances within the input buffer, so the iterator can move past the end of the string and the loop may read beyond the container.
