Issue description:
A heap use-after-free read occurs when the PPD command interpreter copies objects on the PostScript stack. `copy_stack()` passes a pointer to an existing element in `st->objs` to `push_stack()`, but a stack growth reallocation can free `st->objs` before that object is copied, leaving `push_stack()` to read from freed heap memory.
