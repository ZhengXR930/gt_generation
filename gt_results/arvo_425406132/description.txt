Issue description:
An out-of-bounds read occurs when parsing JSON boolean values. The code unconditionally copies 4 bytes from the current input position to check for `true` or the `fals` prefix of `false`, but it does not verify that at least 4 bytes remain in the buffer before calling `memcpy`, so a truncated boolean token near the end of input can read past the end of the buffer.
