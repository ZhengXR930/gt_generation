Issue description:
An out of bounds read occurs in `json_parse()` during JSON string parsing. `file_is_json()` passes a buffer bounded by `b->fbuf` and `b->flen`, but `json_parse_string()` treats a `\u` escape by reading four following bytes and other string content until a terminator without enforcing that all reads remain within the supplied buffer length, allowing reads past the end of the input buffer.
