Issue description:
A global buffer overflow read occurs in `set_blends()` during CFF2 blend processing. The function copies `numBlends` entries from the `blends_` array into `deltas` without enforcing that `blends_` actually contains that many elements, so a crafted `blend` operation can cause reads past the end of the source buffer.
