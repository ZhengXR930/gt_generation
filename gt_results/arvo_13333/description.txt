Issue description:
The Prefix TLV validator in OpenThread's Network Data does not enforce that the prefix length fits within a 16-byte IPv6 address. A malformed TLV with an oversized prefix length passes validation, and later `PrefixMatch()` reads beyond the 16-byte destination address, causing a stack-buffer-overflow.
