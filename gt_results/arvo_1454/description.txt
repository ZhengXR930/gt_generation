Issue description:
An index out of bounds occurs in do_callout() when preparing the offset vector passed to a callout. The code forms a pointer two elements before the current ovector (`Fovector - 2`) and reads and writes those slots to preserve and clear them, but it does not enforce that the working ovector is backed by valid space for these two preceding entries.
