Issue description:
A stack buffer overflow write occurs during decimal number comparison when the comparison result is stored in a plain `decNumber` object without space for any coefficient units. If one operand is a NaN with a large payload, `decNumberCompare()` can produce a result whose payload requires at least one unit, and `decNaNs()` writes past the end of the stack-allocated result buffer because that capacity is not enforced.
