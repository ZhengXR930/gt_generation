Issue description:
When ReplayGain tags are parsed but the bits-per-sample is invalid, the code warns but does not disable ReplayGain processing. This leaves the replaygain apply flag set, and later dithering uses an uninitialized DitherContext, leading to a use-of-uninitialized-value error.
