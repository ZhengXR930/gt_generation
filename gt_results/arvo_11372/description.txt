Issue description:
In the AAT kerning table driver, the bounds check for the actions array multiplies the current depth by an attacker-controlled tuple count in 32-bit unsigned arithmetic, which can wrap to zero and bypass the validation. This allows an out-of-bounds read when dereferencing the actions pointer, leading to a crash.
