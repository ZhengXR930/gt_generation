Issue description:
In wasm3, the parser-only Parse_InitExpr function can dispatch an 'if' opcode to the normal compiler machinery even when no runtime context exists. This results in a null-pointer dereference when the compiler attempts to access code page state through an invalid list pointer, leading to a crash.
