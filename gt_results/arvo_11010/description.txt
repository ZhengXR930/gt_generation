Issue description:
A global buffer overflow read can occur in `OffsetTo::operator()(const void *base)` when it resolves an offset with `StructAtOffset<const Type>(base, *this)` without enforcing that the resulting `Type` lies within the underlying buffer. This allows a crafted unsigned short offset in a table transition to cause `BEInt` reads from memory past the end of the global input buffer.
