Issue description:
An out of bounds read occurs in JSLexer::consumeBracedCodePoint when processing an invalid code point. If JSLexer::error calls forceEOF, curCharPtr_ is set to the end of the buffer, but consumeBracedCodePoint continues to use curCharPtr_ without ensuring it has not reached the end of the buffer.
