Issue description:
A heap-use-after-free occurs during cleanup of a partially built Variant in the JSON decoder. When error cleanup frees the allocated unwrapped body structure, it fails to clear the `dst->data` pointer. Later generic Variant cleanup re-enters the stale object and descends through the request header's authentication token, reading freed memory in `NodeId_clear()`.
