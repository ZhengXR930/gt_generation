Issue description:
An out-of-bounds read occurs in the include-tracking logic used during packet decompression. In `LayerIncludeBuffers::update()`, the code computes a pointer to the selected chunk offset but then reads `include[byteIndex]` and writes `include[byteIndex]` instead of indexing within the chunk, so a large `bitIndex` can access past the end of the 1024-byte chunk because the chunk-relative bound is not enforced.
