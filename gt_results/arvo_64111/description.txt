Issue description:
A negative size can be passed to `insertData()` when setting BGP UPDATE Network Layer Reachability Information. In `setNetworkLayerReachabilityInfo()`, the new NLRI length is subtracted from the existing layer length without validating that the computed difference is non-negative, so a malformed message with inconsistent withdrawn-routes or path-attributes lengths can cause `extendLayer()`/`insertData()` to receive a negative size parameter.
