Issue description:
A heap use-after-free read occurs when parsing chunks before the first IDAT. The code keeps a pointer to `ctx->data` and then calls `read_chunk_bytes()` for the current ancillary chunk; if that call reallocates or replaces the heap buffer, later reads of the chunk contents through the stale `data` pointer access freed memory because the pointer is not refreshed after the buffer change.
