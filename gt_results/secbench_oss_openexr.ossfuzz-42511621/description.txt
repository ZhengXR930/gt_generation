Issue description:
Heap-buffer-overflow in generic_unpack (src/lib/OpenEXRCore/unpack.c): while unpacking/decoding image data (via exr_decoding_run / readCoreScanlinePart), generic_unpack performs an out-of-bounds read of 4 bytes past a heap-allocated buffer. This insufficient bounds checking / incorrect buffer sizing can cause crashes, memory corruption and may enable information disclosure or further exploitation when parsing crafted OpenEXR files.
