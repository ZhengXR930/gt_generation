Issue description:
An incorrect buffer size calculation occurs when parsing a BGP UPDATE message. The withdrawn-routes length and path-attributes length fields are used to locate and copy NLRI data without first enforcing that their combined size fits within the actual message buffer, which can make insertData() memmove more data than the packet contains.
