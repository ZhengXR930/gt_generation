Issue description:
An uninitialized memory use occurs in GNU hash table conversion in `elf_cvt_gnuhash()`. When the input length ends in a partial GNU hash structure, the conversion stops without copying the remaining bytes, leaving part of the destination buffer undefined even though later code can treat the whole buffer as initialized file data.
